## 1. 任务摘要

去除 OSS「接口可用但默认匿名」的不确定性：明确 OSS 上传、URL 查询、调试端点的开放策略与鉴权要求，并实施鉴权与调试端点开关策略，保证 OpenAPI 与运行时一致。

- 范围：「OSS 端点鉴权策略（登录/角色要求）、调试端点开关策略、OpenAPI 与运行时一致。」

## 3. 执行步骤（按顺序执行）

### 步骤 1：盘点 OSS 端点清单

- 盘点 OSS 端点：上传（如 `oss/upload`）、URL 查询、调试三类端点清单。
- 逐端点记录当前鉴权状态（默认匿名）与用途，形成端点清单。

### 步骤 2：输出 OSS 端点策略文档

- 输出策略文档：端点 × 开放策略，逐项明确**匿名 / 登录 / 角色**结论。
- 调试端点明确开关策略（如配置/环境开关）。
- 策略文档置于后端项目内（Claude Code 后端可写区域），路径与提交哈希在回执中声明。

### 步骤 3：实施鉴权

- 按策略文档实施登录/角色鉴权，对齐 Auth/Subject 既有 Sa-Token 用法。
- 调试端点按开关策略处理。
- 401/403 响应一致性：HTTP 状态 + 业务 code + 统一响应体，对齐 G1-02 语义。
- 补齐鉴权断言（对齐 `SubjectContractTest` 风格）。

### 步骤 4：运行测试（预期全绿）

- 三态测试：未登录（401）/ 登录态（通过）/ 越权（403），覆盖上传、URL 查询、调试端点。
- 既有测试全绿（infra / domain / controller 契约测试）。

### 步骤 5：提交回执（执行后由 Backend Codex 复核签署）

回执文件：`handoff/backend-to-frontend/<执行日期>/m4-02-oss-access-control-report.md`（回执目录按回执实际创建日期落位，即执行者写回执当天，AGENTS.md 第 6 条），必须包含：

1. 来源项目、分支、实施提交哈希与回执提交哈希。
2. OSS 端点策略文档路径与端点清单。
3. 三态（未登录 / 登录态 / 越权）测试命令与原始输出（401/403 断言）。
4. OpenAPI 是否变化及结论（如变化，记录提案编号，见禁止事项）。
5. 已知限制（如调试端点开关配置、服务地址、环境变量）。
6. 声明：未修改交接仓库 `api/` 快照、`status/sync-manifest.json`；未伪造验证输出。

- 本任务仅覆盖 OSS 端点鉴权策略（上传 / URL 查询 / 调试）与调试端点开关策略的实施；不得自行改变已批准契约的字段/路径/方法（如有需要必须先提案）。
- 关闭条件（全部满足后 PM 复核关闭 M4-02）：

  2. 未登录 / 登录态 / 越权三态测试通过（对齐 `SubjectContractTest` 风格），且既有测试全绿。
  3. 回执含原始命令输出与提交哈希，Backend Codex 复核签署。
