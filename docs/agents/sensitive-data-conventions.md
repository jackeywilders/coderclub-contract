# 敏感信息脱敏约定（防复发）

> 生效日期：2026-08-15（Asia/Shanghai）
> 适用范围：本仓库所有文档（提案、设计、交接、验收、报告、状态文件）
> 目的：防止真实环境信息再次进入仓库（本仓库将公开）。

## 规则

1. 交接文档中的**真实环境地址（IP/域名）、端口、凭据值、测试账号密码、内部库名/namespace** 一律以占位符呈现，不得写入真实值。
2. 占位符使用语义化名称（如 `<nacos-dev-addr>`、`<mysql-port>`），保持文档可读与结构完整。
3. 真实值对照表由协调 PM 维护在**私有位置**（本机，不在任何 git 仓库内），不得提交到本仓库或任何公开远端。
4. 运行时环境的真实值以后端项目运行时配置（Nacos/环境变量）为准，交接文档不复制。
5. 契约快照 `api/coderclub-openapi.json` 的示例 URL 使用 `localhost`，不得出现真实主机地址。

## 2026-08-15 历史改写说明

- 本仓库全部历史已用 git-filter-repo 做敏感值脱敏改写（113 提交 / 6 分支），真实凭据、IP、端口、测试账号已替换为占位符。
- 改写后**旧提交哈希全部失效**；追溯历史时以协调 PM 私有对照表中的新旧哈希映射为准，或使用改写前备份镜像（本机私有位置）。
- 契约快照 `api/coderclub-openapi.json` 未受影响（SHA-256 保持不变），后端/前端项目不受影响且不公开。

## 新增提交注意事项

- 任何新提交在推送前，建议对新增内容做一次敏感模式自查（IP 形态、`password=` 真实值、连接串）。
- 各角色会话引用"当时环境"时，用占位符或"见 PM 私有对照表"表述。
