    private T data;

    // 静态工厂方法（最终实现 6 个，不含 success(Integer, String, T)——零调用方死代码已删除）

#### PageResult.java — 字段名改为 `list`

**设计决策**：（经确认）`result` → `list`，消除 `setRecords()` 自动覆盖 `total` 的行为。

**实现状态**（M1 已完工，`c01f101` 补了 `pageSize`/`total` 空值防护）：最终实现与设计文档 §2.3 一致：

```java
@Data
public class PageResult<T> implements Serializable {
    private Integer pageNo = 1;
    private Integer pageSize = 20;
    private Integer total = 0;
    private Integer totalPages = 0;
    private List<T> list = Collections.emptyList();  // ← 从 result 改名

    public void setTotal(Integer total) {
        this.total = total;
        if (pageSize != null && pageSize > 0 && total != null) {
            this.totalPages = (total / pageSize) + (total % pageSize == 0 ? 0 : 1);
        } else {
            this.totalPages = 0;
        }
    }
}
```

> **遗留 M2 项**（来自深度审查 D1）：`@Data` 会为 `totalPages` 生成公开 setter，与 `setTotal()` 内部写入形成竞态（Jackson 反序列化 setter 顺序不确定）。M2 建议改 `@Getter @Setter` 并将 `totalPages` 设为只读派生字段。另建议新增 `map(Function<T,R>)` 方法消除控制器手动拷贝样板（D2/A3）。

#### ResultCodeEnum.java

统一枚举合并三份定义，补齐必要值。

**实现状态**（M1 已完工，`980a08b` 删除了零调用方死值 `NOT_ACCEPTABLE(406)`/`INTERNAL_SERVER_ERROR(500)`）：最终为 8 值，与设计文档 §2.4 一致。**注意不再含 `getByCode()` 方法**（零调用方已删）：

```java
@Getter
public enum ResultCodeEnum {
    SUCCESS(200, "操作成功"),
    FAIL(999, "操作失败"),
    REQUEST_PARAM_INVALID(400, "请求参数校验失败"),
    UNAUTHORIZED(401, "未登录或登录已过期"),
    FORBIDDEN(403, "无权限"),
    NOT_FOUND(404, "资源不存在"),
    DATA_BIND_ERROR(400, "数据绑定错误"),

}
```

> 保留重复码 `400`（校验失败/绑定失败）与 `500`（SYSTEM_ERROR）是**有意设计**：枚举名区分语义，码位一致便于前端按语义处理。`INTERNAL_SERVER_ERROR` 与 `NOT_ACCEPTABLE` 曾在实现中出现但因零调用方被移除。

#### 2.4.1 TraceIdFilter

在 `coder-club-common` 中提供 Filter 类：

- 从请求头 `X-Trace-Id` 读取 traceId，不存在则生成 UUID（16位）
- 写入 SLF4J MDC，key 为 `traceId`
- 请求结束时清理 MDC

各模块 starter 通过 `@Bean` 注册：

```java
@Bean
public FilterRegistrationBean<TraceIdFilter> traceIdFilter() {
    FilterRegistrationBean<TraceIdFilter> bean = new FilterRegistrationBean<>();
    bean.setFilter(new TraceIdFilter());
    bean.addUrlPatterns("/*");
    bean.setOrder(Ordered.HIGHEST_PRECEDENCE);
    return bean;
}
```
